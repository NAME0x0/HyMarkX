### 2. `packages/ast` → `@hymarkx/ast`

**Zero runtime dependencies.** No `node:` imports. Must run in a browser.

Exports (single entry point `.` only; `exports` map must not expose deep paths):

```ts
// ---- positions -------------------------------------------------------------
export interface Point { readonly line: number; readonly column: number; readonly offset: number }
export interface Span  { readonly start: Point; readonly end: Point }

// ---- node base -------------------------------------------------------------
export interface NodeBase {
  readonly type: string
  /** Source range. Required: dropping spans is a bug (CLAUDE.md invariant 3). */
  readonly position: Span
  /** Set on nodes produced by transforms; `position` then refers to the origin. */
  readonly synthetic?: true
}
```

**Markdown node types** — CommonMark + GFM only. Names and child-field shapes must match
mdast for the Markdown subset (ADR-0005 structural compatibility), except that
`position` is required here:

`root` (carries `readonly hmxVersion: string`), `paragraph`, `heading` (`depth: 1..6`),
`thematicBreak`, `blockquote`, `list` (`ordered`, `start`, `spread`),
`listItem` (`spread`, `checked: boolean | null` — GFM task lists),
`code` (`lang`, `meta`, `value`), `html` (`value`), `text` (`value`), `emphasis`,
`strong`, `delete` (GFM strikethrough), `inlineCode` (`value`), `break`,
`link` (`url`, `title`), `image` (`url`, `title`, `alt`), `definition`,
`linkReference`, `imageReference`, `table` (`align`), `tableRow`, `tableCell`.

**No footnote nodes.** GFM footnotes are out of scope at this baseline (ADR-0001).

**HMX node types** — define the contract now; HMX-002 will populate them. Note that
these intentionally diverge from `mdast-util-directive`: the label is an explicit field,
not a child paragraph tagged with `data.directiveLabel`.

```ts
export interface Attribute {
  readonly name: string
  /** `null` for a bare attribute (`{disabled}`), distinct from `''` (`{a=""}`). */
  readonly value: string | null
  readonly position: Span   // whole `name=value`
  readonly nameSpan: Span
  readonly valueSpan?: Span
}
/** Ordered, duplicate-preserving: order and duplicates are needed for diagnostics. */
export type AttributeList = readonly Attribute[]

export interface TextDirective      extends NodeBase { type: 'textDirective';      name: string; attributes: AttributeList; children: PhrasingContent[] }
export interface LeafDirective      extends NodeBase { type: 'leafDirective';      name: string; attributes: AttributeList; label?: PhrasingContent[] }
export interface ContainerDirective extends NodeBase { type: 'containerDirective'; name: string; attributes: AttributeList; label?: PhrasingContent[]; children: BlockContent[] }
```

Also export discriminated unions `BlockContent`, `PhrasingContent`, `Node`, plus a
`NodeMap` type keyed by `type` so `visit` can narrow by node type.

**Attribute helpers** (these are where security invariants live):

- `getAttribute(list, name): Attribute | undefined` — last occurrence wins.
- `getAttributeValue(list, name): string | null | undefined`
- `hasAttribute(list, name): boolean`
- `toAttributeRecord(list): Record<string, string | null>` — returns a
  **null-prototype** object created with `Object.create(null)`.
- `isForbiddenAttributeName(name): boolean` — true for `__proto__`, `constructor`,
  `prototype` (case-sensitive). Threat T8 in `SECURITY.md`. Export it; HMX-002 will
  use it to raise `HMX3005`. `toAttributeRecord` MUST skip such names.

**Diagnostics** (shared vocabulary; lives here so parser and compiler agree):

```ts
export type Severity = 'error' | 'warning' | 'info'
export interface RelatedSpan { readonly message: string; readonly span: Span }
export interface Suggestion  { readonly message: string; readonly span: Span; readonly replacement: string }
export interface Diagnostic {
  readonly code: string          // e.g. 'HMX1001'
  readonly severity: Severity
  readonly message: string
  readonly span: Span
  readonly expected?: string
  readonly suggestion?: Suggestion
  readonly related?: readonly RelatedSpan[]
  readonly url?: string
}
export const createDiagnostic: (d: Diagnostic) => Diagnostic  // validates the code shape
export const hasErrors: (ds: readonly Diagnostic[]) => boolean
```

`createDiagnostic` MUST throw a `TypeError` if `code` does not match
`/^HMX[1-5]\d{3}$/` — a malformed code is a programming error, not user error.

**Span utilities:** `pointToString`, `spanToString`, `containsPoint(span, point)`,
`mergeSpans(a, b)` (earliest start, latest end), `SYNTHETIC_SPAN` (all zeros, for
test/builder use), `isSyntheticSpan`.

**Builders:** one factory per node type (`root()`, `paragraph()`, `heading()`, …),
each taking its required fields plus an optional `Span` defaulting to `SYNTHETIC_SPAN`.
Keep them mechanical and typed; do not invent convenience overloads.

**Visitor** in `visit.ts`:

```ts
export const SKIP: unique symbol   // do not descend into this node's children
export const EXIT: unique symbol   // stop the entire traversal
export type VisitorResult = void | typeof SKIP | typeof EXIT
export function visit(tree: Node, enter: (node: Node, parent: Node | undefined, index: number) => VisitorResult, exit?: (...same) => VisitorResult): void
export function visitOf<T extends Node['type']>(tree: Node, type: T, fn: (node: NodeMap[T], parent: Node | undefined, index: number) => VisitorResult): void
```

Depth-first, pre-order, children visited in document order. The visitor MUST NOT mutate
the tree; `visit` takes a readonly view. Traversal must be **iterative (explicit
stack), not recursive** — a 10,000-deep blockquote nest must not blow the call stack
(threat T9).

## PUBLIC CONTRACT

The exported type surface above is specified by the orchestrator. Do not rename, widen,
or "improve" it. If something in it is wrong or impossible, **stop and report** rather
than substituting your own design — the AST is the project's central contract and a
unilateral change here is more expensive than a round trip.

## EDGE CASES

- `Point.offset` is required in HMX (mdast makes it optional) — keep it required.
- `listItem.checked` is `boolean | null`; `null` means "not a task item". Do not use
  `undefined`.
- `image.alt` may be an empty string; that is meaningful (decorative image) and must be
  distinguishable from absent.
- `mergeSpans` must be correct when the two spans overlap or are given out of order.
- Attribute `value: null` (bare) vs `''` (explicitly empty) must never be conflated.

## SECURITY CONSIDERATIONS

`toAttributeRecord` is the prototype-pollution chokepoint (SECURITY.md T8). A test must
assert that after processing an attribute named `__proto__` with value `polluted`,
`({} as Record<string, unknown>).polluted` is still `undefined`.
