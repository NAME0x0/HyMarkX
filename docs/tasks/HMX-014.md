# TASK HMX-014 — Foreign components (TSX interoperability)

**Phase:** 8 · **Assignee:** orchestrator (Codex quota exhausted) · **Status:** DONE

## Outcome (2026-08-17)

Implemented directly, per ADR-0016. Phase 8 complete. Conformance unchanged.

`::island{from="./Chart.tsx" export="RevenueChart" series="monthly"}` records a reference and
emits a placeholder. The compiler never imports, transpiles, or evaluates the module.

## Decisions taken while building

**The compiler executes nothing.** This closes threat T5 (build-time RCE) by construction
rather than by sandboxing: there is no execution path to attack, so there is no sandbox to
get wrong. The cost — `hmx build` output for an island document is not runnable alone — is
documented rather than papered over.

**Framework-agnostic contract, React as an adapter.** VISION lists framework neutrality as
non-negotiable, so the compiler knows only `{ id, from, export, props }`. It has no
framework dependency and its tests reference none. A React adapter in `benchmarks/island/`
proves the contract; it is 20 lines and entirely outside the compiler.

**Explicit `::island`, not an inferred `import`.** MDX infers, which hides a 46 KB decision
inside a line that looks like bookkeeping. Every island also emits `HMX2070` naming the
module, because a cost that is not surfaced is a cost nobody notices.

**`app` mode only.** An untrusted document must not be able to make a host load arbitrary
modules — `HMX3010`.

## Proven, not asserted

`benchmarks/island/prove.mjs` compiles a document, bundles a real React chart with esbuild,
mounts it in a DOM, and clicks it. The caption moves from `monthly · total 171` to
`monthly · total 174`, and three `<rect>` bars render.

| | gzipped |
|---|---|
| The HMX page | **114 B** |
| One React island | **46,273 B** |

Four hundred times the page. That number is the strongest argument in the project for
expressing things in HMX when HMX can express them, and it is measured rather than estimated.

## A security hole my own test caught

The specifier check refused absolute URLs, `data:`, and `file:` — by looking for a scheme.
`//evil.test/x.js` has no scheme: it is protocol-relative, starts with `/`, and passed. A
host bundler would have fetched it from a remote origin.

Found because the test list included it as a case I expected to be rejected, not because
review noticed. Now refused explicitly, along with `\\` UNC-style paths.

## Known limitations

- Props are scalars only. No objects, arrays, callbacks, or children — passing a function
  needs a runtime bridge between HMX state and the framework, which is its own design.
- No server rendering: an island is blank until the host mounts it.
- TSX cannot import HMX. That is a bundler-loader problem, deferred to the integrations work.
