## OBJECTIVE

A `components/Card.hmx` file declaring `props` in frontmatter can be used as `:::Card{…}`
from a document, with its content placed at `::children`, validated by the same schema
machinery as built-ins, rendering to HTML with zero JavaScript.

## REQUIREMENTS

### 1. Compiling a component source into a registry entry

```ts
export interface AuthoredComponent {
  /** Registered name — the file basename, case-sensitive. */
  readonly name: string
  /** The component document's source. */
  readonly source: string
  /** Path used in diagnostics raised inside the component. */
  readonly from?: string
}

export function compileComponents(
  sources: readonly AuthoredComponent[],
  options?: CompileOptions,
): { readonly registry: ComponentRegistry; readonly diagnostics: readonly Diagnostic[] }
```

Each source is parsed, its `props` frontmatter is read into the **existing
`AttributeSchema`** shape from `components/types.ts`, and the result becomes a registry
entry indistinguishable from a built-in to the rest of the compiler. Do not build a parallel
schema type.

Malformed `props` — not a mapping, unknown schema key, bad `type`, `enum` without `values` —
is `HMX2051` (error) with a span inside the component's frontmatter and its path named.

A component whose frontmatter has no `props` key is legal: it accepts nothing.

### 2. Scope

Inside a component, the expression scope is **exactly its resolved props** — defaults
applied, values coerced to their declared type. Nothing else is reachable: not the caller's
frontmatter, not the caller's props, not the component's own non-`props` frontmatter keys.

An identifier outside that scope is `HMX2040` exactly as in Phase 4, with a suggestion drawn
from the prop names.

### 3. `::children`

The caller's content renders at the `::children` position. Rules:

- Zero occurrences is legal — the component discards its children. Emit `HMX2052` (warning)
  **only if** the caller actually supplied content, since silently dropping authored content
  is the failure worth reporting.
- More than one occurrence is `HMX2053` (error).
- `::children` outside a component document is `HMX2056` (error) — there is no caller.
- Children arrive already parsed from the calling document; do not re-parse them.

### 4. Registration and shadowing

- Name is the basename, case-sensitive: `Card.hmx` → `Card`.
- An authored component shadowing a built-in emits `HMX2050` (warning) naming both.
- Two components registering the same name is `HMX2057` (error).

### 5. Recursion

- A cycle (`A` uses `B` uses `A`) is `HMX2054`, and the message MUST name the cycle path.
- Expansion depth is capped at 32; exceeding it is `HMX2055`.
- Both must be reported without exhausting memory or the stack. Test a self-referencing
  component and a three-component cycle.

### 6. Styles

A component may contain `<style scoped>`. Its rules are emitted **once per component used**,
not once per instance — a page with twelve `:::Card` uses gets one copy of the card's CSS.
Scoping is per component, so two components' styles cannot collide.

### 7. CLI resolution

`compile()` keeps taking components as data. Only `@hymarkx/cli` touches the filesystem.

- Discover `components/*.hmx` next to the input file, then at the project root.
- Frontmatter `components:` maps a name to a path, adding to or overriding discovery.
- A missing path is `HMX5004` (error) naming the path.
- Resolution MUST stay inside the project root — reuse the existing traversal guard rather
  than writing a second one.

### 8. Zero JavaScript

A document using authored components emits no `<script>`. Assert it in
`tests/output-size/`.

### 9. Tests

## NON-GOALS

1. No named slots (ADR-0013 defers them).
2. No state, events, or scripts in components — Phase 6.
3. No TSX interop — Phase 8.
4. No parser or AST changes.
5. No plugin API (ADR-0008).
6. No component-level trust escalation: a component runs under the host's trust mode, and
   nothing in a component file may change it.

## EDGE CASES

- A component whose body is empty.
- A prop named `children`, `class`, or `id` — the universal attributes still apply.
- A caller passing an attribute the component does not declare → `HMX2001`, as today.
- A component with frontmatter that is not a mapping.
- A component file that is itself a valid document with prose outside any directive.
- The same component used twelve times — one CSS copy, twelve HTML expansions.
- A component using `{{ }}` where a prop is absent and has no default.
